# Local application verification

- `bkt_web/profile_session.py` quản lý Chrome profile theo kênh và các setting profile; không kill Chrome mở tay và không bấm Đăng lại task đã có `clicked_post_at`.

- TikTok publisher (`bkt_web/tiktok_publisher.py`) on ja/ko accounts: Studio dialogs/tours come in the account's language and Esc does not close the "automatic content checks" dialog, so `MODAL_DISMISS_LABELS` lists decline labels in every account language first (confirm-type "ok"/"확인" last) and falls back to the TUX secondary button (`MODAL_SECONDARY_BUTTON`) / the joyride tooltip button before Esc. Captions go through `_type_caption`: CJK runs are inserted with `keyboard.insert_text` (typing Hangul/Kana key by key into TikTok's editor dropped or reordered text and tripped the caption-mismatch guard), Latin text and hashtags are still typed. Tests: `python3 -m unittest tests.test_publisher_modals` (on the VPS set `TOKMATRIX_CHROME_PATH=/usr/bin/google-chrome PLAYWRIGHT_BROWSERS_PATH=/opt/tokmatrix/.playwright`).
- The FastAPI app runs with `python3 -m bkt_web.server` at `http://localhost:8080`. The existing server process does not automatically reload backend changes; ask before restarting a server you did not start.
- Remake tests: `python3 -m unittest discover -s tests -p test_remake_pipeline.py`. Tests mock story-analysis network calls; the native-renderer smoke test requires installed Playwright Chromium.
- JavaScript syntax: `node --check bkt_web/static/app.js`.
- Remake templates in `bkt_web/remake_templates/` belong to the existing Canvas engine, not the separate HyperFrames projects in `compare_studio/`.
- Reviewed remake scripts are keyed by the source file SHA-256 in `bkt_web/storage/remake_verified_scripts.json`. Preserve explicit source scene times and speaker IDs; never assign speakers cyclically or divide scene durations evenly.
- Native Canvas templates expose deterministic `window.renderFrame(seconds)` for frame-by-frame export. Do not start autonomous animation loops when `?render=1` is present.
- CapCut CLI takes `--out`, not `--output`. TTS cache keys include text, engine, voice and role. A failed voice or render must not fall back to source footage/audio while claiming a completed remake.
- Shared vector library: `bkt_web/static/remake_vector_catalog.json` is the catalog/schema source; `remake_vector_engine.js` renders it. Select `native-vector-v1` on every scene; use `asset` IDs, absolute-time `poses`, named-anchor `attach_to`, and typed `actions`. The composer embeds the engine and catalog for offline frame rendering. Expanded to 110 rigs (quadrupeds, birds, insects/frog, 17 fruits, 10 flowers, tools, props) and 32 actions (`graze`, `pollinate`, `dig`, `hop`, `fly`), engine `1.11.0` with modular `RIG_DRAWERS` architecture.
- Vector rigs, contact rules: `graze` lowers the head (`s.head_down`, quadruped head/horns/ears drawn rotated about `neckPivot` + `neckReach`/`neckDrop`; `localAnchor` rotates `mouth`/`face`/`horn` with it) and only slides the animal horizontally, so the mouth meets the grass top while feet stay on the ground (test `test_graze_lowers_head_to_the_grass_without_sinking_the_body`). Off-centre fruit bodies attach limbs with `hipX`/`armX` in the `drawFruit` spec (grape, banana, mango) — never leave a gap between limb and body. Birds with `canFly` (sparrow) perch with legs and flap only while `fly` is active (`s.flying`). Flower faces scale with bloom (`.26 → .52`) so buds are not covered.
- Vector rig registry: every asset is dispatched through `RIG_DRAWERS` in `remake_vector_engine.js`. Fruits, farm plants/flowers, tools and props register their group function (`drawFruit`/`drawPlant`/`drawTool`/`drawProp`), which keeps the shared parts (limbs, squash, slice, roots, nutrients, hatch). The per-asset drawing lives in `FRUIT_BODIES` (body), `FRUIT_SEEDS` (flesh detail when sliced), `FARM_PLANTS`, `TOOL_DRAWERS` (unknown tools draw as `sprayer`) and `PROP_DRAWERS`. Add a new rig as an entry there, not as another `if (s.asset === …)` branch.
- Vector engine packs (plan `docs/PLAN_remake_vector_farm_health.md`): new rigs/backgrounds go in `bkt_web/static/remake_vector_packs/<pack>.js`, listed in catalog `engine_packs`, and call `RemakeVector.register({ rigs, backgrounds, effects, actionHooks })` with drawing helpers from `RemakeVector.kit`. `register` throws on an id that already exists (packs only add). Every loader uses `remake_vector.engine_sources()` (composer, `renderer_adapters/native_vector.py`, regression test; the library page loads `engine_packs` itself), and it raises `FileNotFoundError` for a missing pack. Never fall back to the core engine: the video would silently miss rigs. Each pack asset declares `pack` in the catalog (`--contact-sheet <pack>` selects by it). Backgrounds are `BACKGROUNDS[preset] = { label, theme, ground_y, draw }`, mirrored in catalog `background_specs`. `catalog.backgrounds` stays a list of ids. `ground_warnings(story)` (returned as `warnings` by `/api/remake/library/validate`) flags people/animals floating above `ground_y`. Weather is `clear|rain|snow|wind|fog|storm|hot`. `wind`/`storm` set `s.wind` unless a keyframe sets `wind`; plants shear with it in both drawing and `worldAnchor` (`windShear`). Pixel regression: `python3 -m unittest tests.test_remake_vector_regression` (every catalog rig, every background × day/night/every weather, every example story; baseline `tests/data/vector_hashes.json`; Chromium runs with software raster `--disable-gpu`, because GPU raster changed hashes under load). A missing baseline fails. Refresh it only on purpose with `python3 tests/test_remake_vector_regression.py --update-hashes`. Contact sheets: `python3 -m bkt_web.remake_vector --contact-sheet <group|pack|ids> --out <file>`. Write them outside `bkt_web/static`.
- Fruit trees and trellis vines (packs `farm_trees`, `trellis`): each rig's `spec` (fruit, slots, fruitScale, flower…) lives in the pack and is mirrored in the catalog, together with anchors `fruit_1`…`fruit_8` (slots past the species count repeat the last one). `PackContractTest` fails if they differ. A tree draws its fruit with the core `FRUIT_BODIES`, centred on `fruit_N`, at size `fruitScale × (0.5 + 0.5·clamp((growth−0.45)/0.55))`. Tree drawings scale with growth like the core `plantPoint`. Vines keep a fixed trellis, so they set catalog `fixed_anchors: true` (anchors do not scale with growth). Pose `fruits` shows the first N slots. `pick` always takes the last visible fruit: at the action's `contact` time (default `start + 0.6`; `showreel` scales it together with start and end) the tree's `fruits` drops by 1, a new fruit actor (no face) appears there, and the `grip` starts, all at once. People reach with IK (`actor_anchor` hand_l/hand_r, the same hand as the grip) and do not move their body; loose `hand` rigs move. `shake` drops exactly one fruit of the tree's species per `fruits` step, and it must touch the background's `ground_y`. Build these events with `remake_vector.tree_pick_events` / `tree_shake_events` (positions from `tree_fruit_placement`); never hand-place the fruit. All fruit trees, temperate ones included (persimmon/peach/pear/cherry_tree), use the single `drawFruitTree` template in `farm_trees.js`; never write a second tree template. `temperate_fruits` only adds the 9 fruits and the `highland_farm`/`snowy_orchard` backgrounds. The engine copies the scene's `background.season` into `s.season` (default summer): spring shows blossoms, autumn turns the canopy orange, winter strips leaves and fruit (except `winterFruit`, e.g. persimmon). Pack fruits/vegetables (group `fruit`/`vegetable`, both drawn by `drawFruit`) compute their own body colour, so each `FRUIT_LIMBS` spec must set `limbColor`; otherwise limbs fall back to the core red (test `test_pack_fruits_and_vegetables_declare_their_limb_colour`). Small bodies set catalog `face_scale`. Root crops (`vegetables` pack) share one `drawRootCrop` template. Parts above ground scale like `plantPoint`; tubers below ground (y > 0) are drawn only when `roots`/`cutaway`/`lift` is > 0. Sea monsters live in pack `sea_monsters` and the wildlife packs draw their own eyes (`face: false`, so they cannot talk). `squirrel` replaced `scrat_squirrel` (too close to the Ice Age character).
- Agrochem and farm-fun packs (`agrochem`, `farm_fun`; plan phases F/G). Safety education only: GHS pictograms on a red-bordered rhombus (never a circle), no brand, active ingredient, dose or text. `spray_drift` (catalog `motion: false`, no channel) poisons a target only where the plume reaches its body (±0.15h): the plume runs 70 px along the nozzle, then the wind (`s.wind`) pushes it up to 190 px to the right of the screen (`plumePoint`/`plumeContactTime` in `agrochem.js`); `toxic` rises over 1.2 s from contact and holds. An attached sprayer (worn on a person's `back`, `held_pose(asset, h, rot, anchor='back')`) is resolved to world space inside the hook (`worldState`), because hooks run before attach. The engine turns `toxic` into plant `damage`/`bend` and a worried/sick face for people and chibi; fish turn belly-up above 0.8; `background.contaminated` 0–1 tints `water`-theme backgrounds and adds scum. `perk_up` has no channel and lowers `damage` to 0; `wilt` uses the `damage` channel. Pack hooks also run after `end` for `hold` actions (`p = 1`), so never return on `!active` when the end state must persist (tug, run_away, wash_produce). `tug`: actor's hands on the target's `grip`, each helper on the one in front (`waist`/`hip`, animals' `tail`); people and chibi IK both hands, animals bite with `mouth` (tilt ≤ 35°, then lifted if still short, like the mouse on the cat's tail); everyone leans away from the radish in phase; at `pop_at` the radish lifts `lift_amount` (default 170) and the chain lets go and falls backwards; `pop_at = end` means the pull fails. Snow sets `shiver` and hot sets `sweat` on human/chibi/animal rigs with a face unless a keyframe sets them (0 = dressed warm); `farm_fun` draws the marks. Tests: `PackContractTest` (tug chain < 12 px, spray drift by wind, wilt/perk_up) and the `test_phase_f_*`/`test_phase_g_*` tests.
- Chibi and medical packs (`chibi`, `medical`; plan phase H): `drawChibi` in `chibi.js` draws the 13 chibi (2.3-head proportion, 27 required anchors, arms by `chibiSkeleton` + `solveArm(…, 14)`); catalog `face_scale: 0.56` and `rest_pose` (hands at ±24, −22) — `pose_defaults` are the adult farmer's, so a rig's `rest_pose` fills only fields no keyframe sets. Chibi `hand`/`grip` = `hand_r` (people: `hand` = `hand_l`). Tapered limbs/handles use kit `taper(ctx, x1,y1,x2,y2, r1,r2, fill, stroke, w)`; `cylinder` stays the gradient helper — never overload it. `medical.js`: 24 props (green/blue crosses, never a red cross), microbes/organs `good_bacteria`, `bacteria_rod`, `virus_spike`, `tooth_chibi` (drawn without their own eyes/mouth: `face()` draws the face), 11 text-free backgrounds with `ground_y: 810`. Props are drawn small and normalised by `RIG_SCALE` in the pack (draw wrapped in `ctx.scale`, catalog anchors already multiplied) — keep the two in sync. Action hooks aim at the target, never at fixed hand offsets: `aimHand` IKs the hand so the held tool's anchor (`action.tool` = a character attached to the actor's hand; `TOOL_ACTIONS` in `remake_vector.py`: brush_teeth→bristles, take_temperature→tip, listen→chest_piece, vaccinate→needle) lands on the target anchor; build the tool pose with `remake_vector.held_pose(asset, height, rotation)` so its `grip` sits in the hand. `wash_hands` keeps both hands ≤ 14 px apart through 6 WHO steps (`WASH_STEPS`, `step` 1–6 or all six); `vaccinate` touches `arm_l` only in `VACCINE_CONTACT` [0.4, 0.6] from a 34 px stand-off (kid worried → happy). Layer `over_face` raises an attached actor's z above its parent at attach time; draw order is a plain z sort. Tests: `PackContractTest` (wash/tool contact/vaccinate window/tool validation) and the `test_phase_h_*` tests in `tests/test_remake_vector.py`.

- Shared infrastructure (Phần II Giai đoạn J, plan §18; packs `outfits`, `vehicles`, `buildings`, `foods`, `containers`, `furniture`, `tools_ext`, `modular_scenes`). Outfits: catalog `outfits.<id>.parts` (back/bottom/shoes/top/head/face_acc) name rows of the data tables in `outfits.js` (`TOPS`, `BOTTOMS`, `SHOES`, `HEADS`, `BACKS`, `FACE_ACCS`), drawn by ~12 shared garment kinds; `regular_*`/`shoes` = keep the character's own piece. `drawChibi` keeps its own drawing and swaps only the layers the outfit has, so hair, face and the character's glasses stay; face-covering pieces (masks, goggles, dive mask, astronaut visor) draw after `face()` through the rig `overlay` hook (`register` → `RIG_OVERLAYS`). An unknown part throws — never fall back to a default shirt (Gemini's first version silently drew a white shirt for 123 of 197 parts). A character's `outfit` is the default and a keyframe `outfit` wins; `warm` outfits turn off the snow shiver. `outfit: none` is pixel-identical to the bare chibi. Object templates are one spec row per rig. Vehicles draw their body above the wheels: `drawVehicle` lifts the drawing by `groundOffset` (wheel bottom, track, rocket fins, lander feet; boats 0) and every anchor is lifted by the same amount (catalog mirrors `kit.VEHICLE_ANCHORS`). Buildings have catalog `rest_pose.growth: 1` (pose_defaults growth is 0.5, which left every building half built); `build` still drives `growth`. `tools_ext` draws every tool itself (unknown id throws) with anchors from `TOOL_ANCHORS`, mirrored in the catalog. Action `channel` must name a numeric pose field and never `x`/`y`/`rotation`/`height` (the engine pulls the channel towards `amount`, so `drive: x` slid cars to x = 1). SVG path strings must be fully interpolated (`M -w*0.5 0` inside a template string draws nothing). Everything a pack destructures from `RemakeVector.kit` must exist there (`TAU` was missing: arcs and angles became NaN and body_world cells, night stars and medical bubbles vanished). `PICTOGRAMS` (traffic, recycling, emergency, prohibition, first_aid, ghs) never call `fillText`. Background hazards `quake` (camera shake), `flood` (water over the actors' legs) and `dust` (haze) are 0–1 settings (`hazards()` in the engine). Shared actions: `ride` puts the rider's `hip` (or `waist`) on the vehicle's `seat` anchor (default `seat_1`) and follows it, behind the body of enclosed vehicles (see-through glass) and in front of open ones (`OPEN_VEHICLES`); `haul` runs a rope from the load's `hitch` to the last puller, every puller's hands IK onto it, load and pullers slide `distance` px (default 80); `carry_together` holds the load between `actor` and `helper` by its `grip_l`/`grip_r` (or its ends). All three are `motion: false`, no channel, `hold: true` (test `SharedActionContactTest`). `remake_vector.localize(story, locale)`; `auto_frame(story)` adds a static camera so small casts (cells, microbes) fill the frame. Tests: `test_phase_j_*` and `PhaseJKLReviewTest` in `tests/test_remake_vector.py`.

- Per-account skins (`docs/PLAN_compare_per_country.md`): channel YAML `creative.skins.<engine> = { variant_id, dna }` picks a variant layout + Creative DNA for that engine only; engines without a skin stay on the legacy renderer (`channelCreative` in `native-engine-adapter.mjs`, `MATRIX_VARIANTS=0` turns all off). A `compare/*` variant channel is valid in niches whose compare score ≥ `COMPARE_TOPIC_MIN` (compare stays out of `allowed_engines`). - Variant QA tools: `node tools/check-previews.mjs --out <dir> --langs de,ja [--engine e|--variant id] --jobs 4` builds previews and runs `hyperframes check` at the production version (0.7.58, pinned in `native-engine-adapter.mjs`; `HYPERFRAMES_BIN` overrides npx), writes `check-report.json`, exits ≠ 0 on any failure; CI `.github/workflows/matrix-variants.yml` runs it on `de`. `tools/similarity-run.sh [--write]` = previews → `creative_similarity previews --jobs` → conflicts. HyperFrames audit false positives found in variants, handled in the kit: a leftover `clip-path` (even `inset(0%)`) makes the audit probe with elementFromPoint, and a full-screen overlay then makes the whole scene look "clipped away" → the kit removes clip-path after clip reveals/transitions (never add clip-path to `.v-scene`); fading an element that has its own background with `opacity` reads as low contrast → pop it with `scale`; rotated text is sampled over its axis-aligned box → keep tilts ≤ 1.5°; a clip that ends at `t` is still shown at frame `t` → every transition hides the previous scene at the boundary; treatment overlays stay inside the image frame (`isolation:isolate`); the `data-fit` script fits to the element's own width minus 3 px.
